# Full і Photography — Task 003

Обидва профілі: A590 IS GM1.01B, CHDK 1.7.0 r6346, GCC 8.3.1, однакові
DISKBOOT.BIN і байти спільних ресурсів. Це packaging-only зміна. Новий UI і
шість запланованих фотографічних скриптів ще не реалізовано. Нові пакети ще
не перевірені на камері; результати користувача стосуються Task 002A baseline.

| Профіль | FLT | Вміст |
|---|---:|---|
| Full | 38 | Усі upstream модулі, скрипти та ресурси; еталон сумісності |
| Photography | 30 | Той самий набір без семи ігор, календаря і SOKOBAN.LEV |

Вилучено тільки `4wins`, `mastmind`, `reversi`, `snake`, `sokoban`, `sudoku`,
`tetris`, `calend` (.flt) і `CHDK/GAMES/SOKOBAN.LEV`. Це самостійні simple
modules із динамічними пунктами Games/Tools, без знайдених статичних споживачів.
Імена прибраних ігор зникають зі списку; батьківський пункт Games лишається.
Збережений user-menu shortcut на вилучений модуль потрібно прибрати вручну.
Решта діагностичних утиліт, uBASIC, text viewer та всі upstream scripts
залишаються для сумісності. Photography поки не приховує всю складність Classic.

Це **не скорочує resident core RAM**. При відкритті Games/Tools може зменшитися
динамічно виділена пам'ять меню; це не виміряний виграш у режимі зйомки.

## Встановлення і повернення

Збережіть відомий робочий Task 002A Full ZIP і поточну SD-копію окремо.
Перевірений користувачем спосіб: FAT16 32 MiB першим, FAT32 другим, BOOTDISK,
LOCK. Розмітку вже працюючої карти **не потрібно змінювати**.

Найкраще перевіряти новий пакет на окремій карті. Якщо оновлюєте поточну:
спочатку повний backup з фото, потім чисте дерево CHDK із вибраного профілю,
а не накладання поверх старого. Накладання залишить виключені FLT на SD.
Не копіюйте старі CFG/користувацькі shortcuts у перший контрольний запуск.
Після заміни файлів потрібне вимкнення/увімкнення; меню модулів кешується.
Майбутнє перемикання Simple/Classic UI — інша операція, запланована без restart.

Windows-команди з `SD_INSTALL_WINDOWS.md` застосовні до обох профілів:
змініть filename suffix `full` на `photography`, перевірте `manifest.profile`,
очікуйте відповідно 38 або 30 FLT. `PACKAGE-MANIFEST.json` містить окремі
checksum/size кожного payload-файла; MODULE-INVENTORY.json описує всі 38 модулів
і їхню належність до Photography. Для повного відкату див. SD_ROLLBACK.md.

Нові ZIP мають інші хеші через документи/manifest/source commit; незмінність
DISKBOOT перевіряється окремо проти Task 001. Назви artifacts і ZIP однозначні:
`CHDK-A590IS-101B-1.7.0-r6346-full` та `...-photography`.
У кожному artifact: ZIP, SHA256, JSON звіт, module inventory і порівняння профілів.
